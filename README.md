## Reproducibility

C++20; CMake/Ninja; OpenCASCADE7.9.3; Eigen; Gmsh; SuiteSparse/CHOLMOD with METIS. The `engineering` CMake preset builds the current head and numerical verification. The `engineering_generate` build target writes CAD/readback artifacts and engineering reports. The root `core` and `sanitize` presets build/test the host-side machine core and retained legacy reference code; `sanitize` enables AddressSanitizer and UndefinedBehaviorSanitizer. Root CTest also executes Python source-record validators for production evidence, IF-B01/RP2350 allocation and published mechanism artifacts; the C++ replacement engineering suite itself has no Python runtime dependency. When a compiler or cache option changes, configure with `cmake --fresh --preset <name>` so preset values are fully reapplied. The separate Pico SDK project under `software/machine/rp2350` builds target UF2 images. No build is physical qualification or permission to energise equipment.

The current **head R6 / feed R6 / measuring R1 / mechanism R3** source state extends the prior 492-part R1 mechanism to 507 source occurrences: eight R2-selected guard/actuator solids and seven R2 payoff solids (welded spool, Ø20 spindle, two 6204-pocket posts, base, brake disc, caliper bracket). ## Manufacturability, cost and Komax position

- Custom metal parts are limited to H001/H002/H003/H004, F101–F112, M201, the guard G101–G106 and payoff P001–P007 parts; all are prismatic, turned or welded-laser parts for the available laser/brake/CNC, with dimensioned A3 sheets for H003, F101 and M201 (guard/payoff R2 sheets remain to be produced). F101 bearing seats (12/15 j5 matched to measured bores, cylindricity1 µm, Ra0.4 µm) and the blade seat require outsourced grinding; that is a stated process requirement, not demonstrated shop capability.
- Purchased parts are catalogue items from HIWIN, STEPPERONLINE, R+W, MISUMI, SKF, SEEGER, Kübler, Autonics, Rittal and the documented controls suppliers. Some records retain observed unit prices, but controls/cabinet selections are incomplete and no delivered or total machine cost exists or is estimated here.
- Not fabrication released: the CAD includes pressure/tensioning slides, wire guides and measuring-wheel support, plus the R2 [guard/payoff selections](docs/26-guard-and-payoff-selection.md); actual guard/panel mounts, door hardware, spool/spindle/brake load validation and all physical validations remain unresolved. Final cabinet hardware is also unselected. An initial logical cabinet control/safety design input exists in [docs/22-controls-and-wiring.md](docs/22-controls-and-wiring.md) with a proposed terminal/enclosure identity table, but its DC switching duty, regeneration/discharge, guard release, terminals, enclosure, PE, mains protection and physical validation are unresolved. Not yet qualified: blade pair, 13/10 shaft regional stress holds, adapter peak (improved justified boundary, still REFINE), housing/collar contact, bearing thermal field, joint preloads, any physical accuracy or endurance.
- Komax's published length repeatability is ±(0.2%+1 mm); the S1 target ±(0.20 mm+0.05%) is tighter on paper and **unmeasured**. No claim of Komax-level performance is made; see [the benchmark](docs/02-benchmarks-and-sources.md).
