## Scope

This is a **sampled nominal bending-stiffness audit**, not a continuous tolerance proof. It does not validate local peak stress, fatigue, Saint-Venant torsion of an open keyway, true helical thread roots, bearing/housing compliance, preload or physical accuracy. A minimum principal I does not alone bound nominal bending stress about a shifted centroid. Existing3× stress sensitivity is still a screen, not an established notch factor. No force, material or release gate is relaxed by this report.
