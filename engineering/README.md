This directory contains the replacement engineering work. **It is not a fabrication or energisation release.** The earlier generic-stage CAD and the “exact / zero-uncertainty” purchasing and physics reports are not the authority for this revision.

## Evidence and model discipline

- Read [sources/catalogue-evidence.md](sources/catalogue-evidence.md) before using any numerical rating.
- A manufacturer's **static load rating**, **maximum working load**, **dynamic load rating**, and **repeatability** are different quantities.
- Specified load cases are design/test requirements, **not measured wire-cutting forces**.
- Materials, friction, contact, preload, support stiffness, motor temperature and wire-lot behaviour require qualification. No script can remove that requirement.
- Models must expose failed checks, numerical convergence and physical-validation holds. Exit success is not machine certification.
- All new analysis and CAD computation use C++20. Do not extend the legacy Python calculator as the machine's engineering authority.
- Prices observed on a product page are merchandise prices, not Tunisia-delivered quotations. No purchase, vendor contact, freight booking or duty eligibility verification has occurred.
